# Noordster

Noordster is Sam Hoven's personal operating system: one place for income, health, food, learning, money, calendar, and life. It turns scattered tools into a single mission-control dashboard with clear priorities, real-time status, and a cinematic visual style.

## What it does

- Keeps the overview of business, body, mind, money, and life
- Shows target progress toward earnings, training, learning, and balance
- Gives the user a calm, decisive view instead of chaos
- Keeps the system aligned with Sam's rules: one source of truth, few notifications, explicit approval before external actions, and no fake certainty

## Open locally

From the repo root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/cockpit/index.html
```

## Core idea

The cockpit is built as a live command center:

- left rail: life domains and workstreams
- center: current mission and status cards
- right rail: priorities, system alerts, and AI team
- dark cinematic theme with calm neon accents
- balanced design to support goals, order, and clarity

## Status

This is the first polished visual version: a live dashboard for the mission, not a full production personal OS yet.
